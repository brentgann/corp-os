# _incoming

Material waiting to be migrated. Not a layer, not part of the OS: the leading
underscore keeps it out of `build_index.py`'s undeclared-directory report,
which is correct — this is input, and it stops existing once it has been
brought across.

It exists so `corp-os-migrate` has something real to file. Twelve items in
three populations, which is the distinction the skill has to make:

- 8 notetaker summaries whose transcripts are still fetchable
- 3 reconstructions from a cancelled tool, originals gone for good
- 1 calendar log, which is a record that meetings happened and is not source
  material at all
