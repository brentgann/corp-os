# my stuff

Started this after the second time I rebuilt the same analysis from scratch.
Rules I actually follow:

- Every note gets a **How I'd be wrong** line. If I can't write one, I don't
  understand the thing yet and the note isn't ready.
- Friday pass: reread anything touched that week, delete what turned out to
  be noise. Takes twenty minutes.
- **I never write down anything about people.** Learned that the hard way at
  a previous job. Names go in my head or nowhere.
- File names are the index. There isn't a real one.
