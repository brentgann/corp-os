# Web fonts for the single-page build

Embedded by `build_page.py --standalone` so the exported file renders the
same with no network. Separate from `../fonts/`, which serves the PDF
renderer and carries a different three families.

| Family | Cuts | Licence |
|---|---|---|
| Archivo | 500, 600, 700 | SIL Open Font License 1.1 |
| Source Serif 4 | 400, 400 italic, 600 | SIL Open Font License 1.1 |
| JetBrains Mono | 400, 500, 700 | SIL Open Font License 1.1 |

All OFL and redistributable. Sourced from the `@fontsource` packages of the
same names; latin subsets only.
